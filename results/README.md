# Results

Store structured experiment outputs here.

Recommended files:

- `<method>_<dataset>_<run_id>.json` — configuration + detector events + summary metrics.
- `<method>_<dataset>_<run_id>.csv` — tabular per-block/per-run measurements.
- `changes.md` — intentional code changes made for compatibility or thesis extensions.

Never overwrite a prior run. Use a new run ID.
